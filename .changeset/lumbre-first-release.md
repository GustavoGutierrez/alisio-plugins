Add `@alisio/plugin-lumbre`: a web builder app for Alisio. Describe a landing page or a small app and the model you pick builds it in a chat per project; every change is shown as a reviewable diff (accept all or per file), build errors trigger at most two automatic fix proposals, and the result opens live in your browser from a loopback dev server with hot reload, with a safe static thumbnail inside the app. Stacks: HTML/CSS/JavaScript (optional Tailwind), Vite + Tailwind, React + Vite + Tailwind, Astro + Tailwind and Next.js; pinned versions with committed lockfiles installed by `npm ci --ignore-scripts`, extra packages only from a per-stack allowlist. Projects keep their history in Lumbre's private state and can be exported to the workspace or downloaded as a ZIP. English and Spanish follow Alisio's language.

# Índice de plugins

Instala cualquier plugin con `alisio install npm:<package>`. Consulta la [portada del catálogo](/es/).

- [@alisio/plugin-atlassian](./atlassian) — Read-first Jira and Confluence Cloud tools for Alisio with strict environment configuration, opt-in writes, and untrusted-content framing.
- [@alisio/plugin-brave-search](./brave-search) — Brave Search for coding agents: LLM Context grounding with pre-extracted page content under a token budget, plus a compact web search fallback.
- [@alisio/plugin-cardsmith](./cardsmith) — Generates finished card images from chat requests: social cards, certificates, badges, banners, photo composites, charts and dynamic data cards.
- [@alisio/plugin-context7](./context7) — Resolve library names and fetch third-party documentation from the Context7 hosted service.
- [@alisio/plugin-deepseek](./deepseek) — Dedicated DeepSeek model provider for Alisio: Chat Completions and Responses with metadata-rich catalog discovery and context windows.
- [@alisio/plugin-free-models](./free-models) — Free LLM access for Alisio with minimal setup: Kilo Code works with no account or key, plus free tiers of other OpenAI-compatible services.
- [@alisio/plugin-frontsmith](./frontsmith) — Runs a gated frontend engineering workflow with specialist agents, deterministic rule packs, architecture, accessibility and token checks, and a reproducible visual-fidelity pipeline.
- [@alisio/plugin-google-chat](./google-chat) — Google Chat tools for Alisio with two independent, fail-closed authentication modes, read-first defaults, and untrusted-content framing.
- [@alisio/plugin-laya](./laya) — Local Laya decision provider for Alisio: fast select, boolean and ordinal decisions from a managed, isolated Laya server, with explicit-consent setup and no data leaving the machine.
- [@alisio/plugin-literature-research](./literature-research) — Safe zero-key scholarly metadata research tools for Alisio.
- [@alisio/plugin-material-icons](./material-icons) — Material Icon Theme for the Alisio web UI: a self-contained icon-theme provider with the vendored Material Icon Theme SVGs and VSCode-style manifest. (`ui`, `icon-theme`)
- [@alisio/plugin-openai](./openai) — Official OpenAI Responses API model provider for Alisio.
- [@alisio/plugin-opencode](./opencode) — OpenCode Console (Zen) model provider for Alisio: fail-closed Responses, Chat Completions and Anthropic Messages routing over the unauthenticated OpenCode catalog.
- [@alisio/plugin-opencode-go](./opencode-go) — OpenCode Go model provider for Alisio: fail-closed Responses, Chat Completions and Anthropic Messages routing over the unauthenticated OpenCode Go catalog.
- [@alisio/plugin-openrouter](./openrouter) — OpenRouter OpenAI-compatible model provider for Alisio.
- [@alisio/plugin-scribe](./scribe) — Scientific writing studio with agent-assisted LaTeX drafts, revisions, assets and isolated PDF builds.
- [@alisio/plugin-semantic](./semantic) — Local semantic search engine for Alisio (LanceDB + multilingual-e5-small on ONNX) plus a Notebook app that answers only from your sources, with citations.
- [@alisio/plugin-swarm](./swarm) — Runs a handoff-driven swarm of specialised agents, each in its own git worktree, with durable handoffs, deterministic quality gates and a human approval gate.
- [@alisio/plugin-telemetry](./telemetry) — Privacy-first local agent observability for Alisio: a SQLite source of truth, bounded agent-facing query tools, and opt-in OpenTelemetry-aligned OTLP export.
- [@alisio/plugin-wayfinder](./wayfinder) — Coordinates a resumable specification-driven development workflow by delegating bounded phases to fresh Alisio child sessions and persisting validated artifacts in the workspace.
- [@alisio/plugin-web-search](./web-search) — Privacy-conscious, provider-neutral web search tools for Alisio.
- [Evalua](./evalua) — Guides teachers through a short interview for printable school math exams and keeps the teacher profile, workspace and exam numbering. (`methodology-harness`)
- [Thesis Studio](./thesis) — Plans, researches, drafts and typesets university theses with verified evidence and deterministic quality gates. (`methodology-harness`)

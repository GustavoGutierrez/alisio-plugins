# Third-party components

- node-tectonic 1.1.0 and Tectonic: MIT; platform dependency includes its license.
- PDF.js (pdfjs-dist): Apache-2.0; see dependency LICENSE.
- compiler/bundle.zip: TeX Live snapshot from the build environment. Individual TeX and font packages retain their original licenses (including LPPL, Knuth TeX licenses, GPL and font licenses). The archive includes the Debian TeX Live copyright/license inventory under LICENSES. This data is not relicensed under the plugin MIT license. The snapshot contains unmodified original package files; the Tectonic format entry is generated by the release script.

The maintainer builds the snapshot using scripts/vendor-tex-bundle.py; users receive the built archive and never need TeX Live installed.

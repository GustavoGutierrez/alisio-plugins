# @alisio/plugin-free-models

## 0.1.0

### Minor Changes

- f924a76: Add `@alisio/plugin-free-models`: a model provider with free LLM access and minimal setup. Kilo Code
  with `kilo-auto/free` works by default with no account or key; other free OpenAI-compatible
  providers are one select away, list only free models, show their free limits in plain words, and
  ask for a key only when the provider needs one. Includes a `help` command and an optional Free
  models guide page on Alisio 0.11.5 or newer.

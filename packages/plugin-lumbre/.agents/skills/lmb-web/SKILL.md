## Design

- Start from the audience and the goal: one clear headline, a supporting line, one primary action.
- Pick a small palette (one accent, neutrals) and one or two type sizes per level; keep spacing on
  a consistent scale. Prefer system fonts or an allowlisted font package.
- Lay out mobile first; check that nothing overflows at 360 px wide.
- Write real, specific copy for the brief. Mark placeholders clearly (for example "Your phone
  number") instead of inventing facts.

## Accessibility

- One `h1`, ordered headings, landmarks (`header`, `main`, `footer`), alt text for meaningful
  images, labels for every input, focus styles kept visible, contrast of at least 4.5:1 for text.

## Iterating

- Change only what the request needs and keep the rest of the design consistent.
- Offer one recommended approach without technical questions; ask only when the request is
  genuinely ambiguous.
